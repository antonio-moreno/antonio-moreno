## Proyectos personales

Servidor de pruebas montado sobre una **HP Z440**, con Debian 13, Intel Xeon E5-2630 v3 y NVIDIA Quadro M2000 de 4 GB. Entorno para experimentar con despliegues de IA generativa, LLM, chatbots y asistentes locales, además de contenedores y servicios auxiliares.

### Homelab y almacenamiento autoalojado

Laboratorio doméstico basado en OpenMediaVault y Docker Compose. Incluye servicios de gestión fotográfica con Immich y PhotoPrism, almacenamiento SSD/HDD, acceso remoto con Tailscale y pruebas de DNS y filtrado con AdGuard Home.

### Raspberry Pi, redes e IoT

Uso de Raspberry Pi para servicios ligeros de red y experimentación. También desarrollo pequeñas pruebas con placas RP2040, MicroPython, pantallas LCD y comunicación I²C.
